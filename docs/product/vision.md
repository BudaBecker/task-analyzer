# Product vision

Task Analyzer helps a person manage their work and understand completion patterns and missed deadlines. The product combines the Desktop App with the Task Analyzer Server: the server concentrates business rules, persistence, and analysis, while the Windows desktop provides simple interaction and presentation.

## Problem and intended outcomes

Personal task lists record what needs to be done but can make it difficult to understand completion time and deadline performance. Task Analyzer brings task management and those measurements together, using persistent task history as the basis for analysis.

The intended outcomes are to make approaching deadlines visible, help the user recognize completion patterns, and explain how completed work performed against its deadlines. The MVP prioritizes dependable server behavior and a usable desktop interface.
